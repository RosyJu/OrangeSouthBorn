# 功能指南

## 涉及到服务器资源的功能

必须覆盖服务器资源包才能有效果
包括但不限于以下内容,并不是所有功能都会起效果,可能部分功能在特定服务器情景下不起作用:

### 准备工作

- 安装任意可以修改资源包顺序的模组
- 例如以下模组
  -  [My Resource Pack, My Choice](https://modrinth.com/mod/my-resource-pack)
  -  [ServerPackUnlockerPlus](https://modrinth.com/mod/serverpackunlockerplus)
  -  [Server Pack Unlocker](https://modrinth.com/mod/server-pack-unlocker)

### 功能

- 钓鱼贴图修改
- BossBar背景修改
- 刻意的贴图修改
- 不符合Minecraft风格的图案
