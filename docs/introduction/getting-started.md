# 快速开始

## 安装

### 前置准备

- (必须) Minecraft 1.21.4 - 1.21.11

- (建议) Fabric loader

- (建议) Windows10或Windows11系统

### 开始安装

- 通过 [gitee](https://gitee.com/RosyJu/orange-south-born/raw/MagicTown/橘南生.zip) 下载资源包

- 如果你是Windows10或Windows11系统,可以选择使用以下方式下载资源包

::: code-group

``` cmd
curl https://gitee.com/RosyJu/orange-south-born/raw/MagicTown/橘南生.zip
```

:::

1. 将资源包放入Minecraft的资源包目录

![](/public/ResourcePackFilePack.png)

1. 在Minecraft中启用资源包

![](/public/ResourcePackScr.png)
