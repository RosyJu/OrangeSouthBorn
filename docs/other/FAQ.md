# 常见问题

若此页面中所存在的解答方案不能够解决你所遇到的问题,请在QQ群中@群主反馈,我会尽快回复你.

## 盔甲及鞘翅纹理不显示

- 盔甲及鞘翅一类物品需要前置模组支持 [```variants-cit```](https://modrinth.com/mod/variants-cit)

## 只有部分物品改名生效

- 确认资源包覆盖在最上层
- 如果是在服务器中,尝试将资源包覆盖在服务器上 [```My Resource Pack, My Choice```](https://modrinth.com/mod/my-resource-pack)

## 我想给物品增加一个新命名

- 加入QQ群私信群主,请求为物品添加新命名
- 你需要提供的信息 ```模型名``` ```模型WIKI截图``` ```新命名```
