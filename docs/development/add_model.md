# 添加模型

## 前置准备

- 确保了解模型文件内容,这包括模型源代码修改
- 了解Minecraft资源包结构
- Minecraft美术要求
- 不懂会问

## 开始

- 下载示例文件
- - [示例文件.zip](https://gitee.com/RosyJu/orange-south-born/raw/MagicTown/示例文件.zip)
- 解压示例文件,查看文件结构

## 文件结构

```text
[zhCn_Name]
├── models/
│   ├── [model].json
│   ├── ...更多json模型文件
├── textures/
│   ├── [item].png
│   └── ...更多贴图文件
└── image.png
└── setting.json
```

### [zhCn_Name]

一个中文名文件夹,建议为物品的中文名称,比如物品可以改名为```钻石```,那么这个文件夹名最好为```钻石```

### models

models文件夹主要用来存放模型文件,不存贴图文件

### textures

textures文件夹主要用来存放贴图文件,不存模型文件

### image.png

该图片是展示再文档模型列表的图片,建议高度或者宽度不超过64像素,否则会导致图片加载缓慢

### setting.json

该文件主要为了设置模型的基本设置

```json
{
  "enName": "nature_axe", // 物品的英文名,不得与其他物品冲突,可以增加自定义后缀,仅可包含数字,小写字母,下划线
  "name": [
    "自然之斧" // 该值为一个数组,包含了允许铁砧修改的名称
  ],
  "model": [
    "model" // 该值为一个数组,包含了需要加载的模型文件名,无需后缀.json
  ],
  "item": [
    "#斧" // 该值为一个数组,包含了可用的物品,#开头为标签类目,若不带#则为单独的物品名
  ],
  "itemModel": {
    "enable": false, // 设置为true代表使用自定义的物品模型映射
    "data": {} // 若enable为true则名称条件匹配后使用data的条件,而不是直接输出模型
  }
}
```

### 命名空间规范

再模型中命名空间规范必须等于[zhCn_Name],否则会导致模型无法加载

### 注意事项

若模型在使用中出现问题,则可能面临被撤回的风险
